# Juvilete A. Catungal — Portfolio

Personal portfolio highlighting UI/UX design, technical documentation, and
Computer Engineering projects.

## View the portfolio

After GitHub Pages is enabled, the site will be available at:

<https://velumi09.github.io/juvilete-portfolio/>

## Run locally

Open `index.html` in a browser. Keep the `assets` folder alongside it so
project previews, tool marks, and the profile image load correctly.

## Project structure

- `index.html` — complete static portfolio, including styles and interactions
- `assets/` — project imagery, profile image, illustrations, and tool logos

The contact form prepares an email draft in the visitor's email app; it does not
send or store information through a website backend.
